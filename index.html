SQL Setup

Panduan Tabel Supabase

Jalankan skrip SQL berikut pada menu SQL Editor di dashboard proyek Supabase Anda agar sinkronisasi berjalan otomatis: 

CREATE TABLE IF NOT EXISTS public.baji_artha_mart_sync (
  id TEXT PRIMARY KEY,
  payload JSONB NOT NULL,
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

ALTER TABLE public.baji_artha_mart_sync ENABLE ROW LEVEL SECURITY;

DROP POLICY IF EXISTS "Allow public read write" ON public.baji_artha_mart_sync;

CREATE POLICY "Allow public read write"
ON public.baji_artha_mart_sync
FOR ALL
USING (true)
WITH CHECK (true);

Catatan: Data tetap tersimpan otomatis di penyimpanan lokal browser sehingga tetap aman dan dapat digunakan meskipun sedang offline.
