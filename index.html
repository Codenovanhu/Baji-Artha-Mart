Panduan Tabel Supabase

Jalankan skrip SQL berikut pada menu SQL Editor di dashboard proyek Supabase Anda untuk menyiapkan tabel penyimpanan JSON terpusat: 

CREATE TABLE IF NOT EXISTS baji_artha_mart_sync (
  id TEXT PRIMARY KEY,
  payload JSONB NOT NULL,
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

ALTER TABLE baji_artha_mart_sync ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Allow public read write"
ON baji_artha_mart_sync
FOR ALL
USING (true)
WITH CHECK (true);

Catatan: Aplikasi tetap menyimpan data secara otomatis di penyimpanan lokal browser sehingga tetap dapat beroperasi meskipun sedang offline.
